## Autumn beauty scene

The current autumn scene uses original evaluated Blender architecture, fixed-camera baked radiance and depth-resolved vegetation. CC0 material / model sources and processing are documented in [the beauty scene credits](assets/models/beauty/CREDITS.md). Photographic moodboard references and the offline Blender project are not published as website assets.
